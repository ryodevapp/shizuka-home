しずかなホーム画面の利用規約

この利用規約(以下「本規約」といいます)は、iOSアプリケーション「しずかなホーム画面」(以下「本アプリ」といいます)の利用条件を定めるものです。本アプリを利用される方(以下「利用者」といいます)は、本規約に同意したうえで本アプリをご利用ください。

1. 適用

本規約は、本アプリの利用に関する一切の関係に適用されます。本アプリをダウンロードし、または利用した時点で、利用者は本規約に同意したものとみなします。

本アプリはApp Storeを通じて配信されます。Apple Inc.が定める条件と本規約が異なる場合、本アプリの利用そのものについてはApple Inc.の定めが優先します。

2. 本アプリの提供内容

本アプリは、ホーム画面に置くウィジェットに、利用者が選んだアプリの名前を並べて表示します。あわせて、選んだアプリを一定の時間休ませる機能(集中・アプリを休ませる時間)、アプリを開く前に少し間をおく機能(開く前のひと呼吸)、今週のふりかえりを提供します。

ホームに並べるアプリ、スクリーンタイムの情報、ふりかえりに出る利用の記録を、本アプリは端末の外へ送信しません。当方はサーバーを持たず、利用者に関する情報を集めません。本アプリが行う通信は、有料版の購入と購入の復元のための、Apple Inc.のApp Storeとの通信だけです。

データの取り扱いの詳細は、あわせて公開しているプライバシーポリシーをご確認ください。

3. スクリーンタイムの機能について

集中とアプリを休ませる時間は、Apple Inc.がiOSに用意しているスクリーンタイムの仕組みを使って、利用者が選んだアプリを休ませます。この仕組みを使うには、利用者ご自身による許可が必要です。

本アプリは、利用者が自分の端末で、自分のために使うものです。保護者が子どもの端末を管理する用途や、他の人の端末を管理する用途には対応していません。

アプリを休ませる設定は、利用者がいつでも本アプリの中から外せます。

開く前のひと呼吸は、ショートカットAppのオートメーションから本アプリを呼び出して働きます。オートメーションは、当方が用意したショートカットを利用者が取り込むか、利用者ご自身が作成するもので、利用者ご自身が管理します。

4. 有料版について

本アプリは、無料でご利用いただける範囲に加えて、追加の機能をまとめた有料版を提供します。ホームに並べるアプリ、開く前のひと呼吸(アプリ1つ)、アプリを休ませる時間(1つ)、簡単なふりかえりは、無料の範囲に含まれます。有料版では、集中、詳しいふりかえり、着せ替えを使えます。また、開く前のひと呼吸はアプリの数の上限なく、アプリを休ませる時間は8つまで使えます。

有料版は買い切りです。一度のお支払いで、以後の追加のお支払いなくご利用いただけます。価格は、購入画面に表示する価格(税込)です。自動の請求はありません。有料版(買い切り)はファミリー共有に対応しており、ファミリー共有のグループの家族も使えます。おためしは共有されません。

購入の前に、有料版を14日間無料で試せます(以下「おためし」といいます)。おためしはApp Storeで0円の商品として受け取るもので、お支払いはありません。始めてから14日たつと自動で終わります。おためしが終わっても、有料版に自動で切り替わることはなく、請求もありません。おためしを使えるのは、同じAppleアカウントで1回だけです。

おためしが終わったときは、着せ替えは「藍」に戻ります。集中などの設定は、消さずに端末に残します。無料で使える数を超えたアプリを休ませる時間とひと呼吸は、消さずに止めておき、有料版を購入すると元どおりに動きます。

お支払いおよび返金の手続きは、いずれもApple Inc.が行います。当方は利用者のクレジットカード番号等の決済情報を受け取らず、保持しません。返金をご希望の場合はApple Inc.にお問い合わせください。

購入内容は、同じAppleアカウントであれば「購入を復元」から復元できます。機種を変更された場合も同様です。

本アプリは、購入の記録をApp Storeとの通信で確かめます。最後に確かめてから7日のあいだ記録を確かめられないときは、一時的に無料の範囲に戻ります。通信できる所で本アプリを開くか、「購入を復元」を行うと、有料版に戻ります。
